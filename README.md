# TURAN (TRN) — Telegram Mini App

Полноценный стартовый проект clicker-игры с оригинальным интерфейсом, серверной игровой логикой и SQLite-базой данных.

> Важно: TRN в этой версии — **внутриигровые очки**, а не криптовалюта, не токен Ethereum/TON и не денежный баланс. Нет покупки/продажи, вывода средств или обещания доходности.

## Возможности

- Вход через проверку `initData` Telegram Mini Apps.
- Локальный демонстрационный режим для разработки.
- Серверный баланс, клики и энергия.
- Восстановление энергии и пассивный доход.
- Улучшения: сила касания, запас энергии, скорость восстановления, автоматический доход.
- Задания и одноразовые награды.
- Реферальные ссылки через `startapp`.
- Таблица лидеров.
- SQLite с сохранением данных между перезапусками.

## Требования

- Node.js 20 или новее
- npm
- Telegram-бот, созданный через официальный `@BotFather` (для публикации)

## 1. Установка

Распакуйте архив, откройте терминал в папке проекта и выполните:

```bash
npm install
```

Создайте файл `.env` на основе `.env.example`.

Для локального тестирования оставьте:

```env
NODE_ENV=development
PORT=3000
DATABASE_FILE=./data/turan.sqlite
```

Запустите:

```bash
npm run dev
```

Откройте `http://localhost:3000`. В локальном режиме проект использует демонстрационного игрока. Данные сохраняются в `data/turan.sqlite`.

## 2. Подключение Telegram

1. Откройте Telegram и найдите `@BotFather`.
2. Создайте бота командой `/newbot`.
3. Скопируйте токен бота.
4. Укажите его в `.env`:

```env
BOT_TOKEN=ВАШ_ТОКЕН_ОТ_BOTFATHER
NODE_ENV=production
```

5. Разместите приложение на сервере с HTTPS.
6. В `@BotFather` настройте Mini App / Web App и укажите HTTPS-адрес приложения.
7. В `public/app.js` замените `YOUR_BOT_USERNAME` на username своего бота (без `@`).

В production сервер принимает только действительные Telegram `initData`. Не отключайте эту проверку и не включайте dev-режим на публичном сервере.

## 3. Проверка

- `GET /health` — проверка доступности сервера.
- `GET /api/me` — профиль и игровой баланс.
- `POST /api/click` — нажатие.
- `POST /api/buy` — покупка улучшения.
- `POST /api/claim-task` — получение награды.
- `GET /api/leaderboard` — рейтинг.

API защищён проверкой Telegram `initData` и ограничением частоты запросов. Все изменения баланса выполняются сервером.

## 4. Перед реальным запуском

Это рабочая стартовая версия, но перед публичным запуском рекомендуется:

- Перейти на PostgreSQL, если ожидается большая аудитория.
- Добавить мониторинг, резервные копии базы и журнал аудита.
- Настроить проверку фактического выполнения внешних заданий; сейчас задания являются внутренними игровыми заданиями.
- Добавить административную панель и инструменты модерации.
- Проверить нагрузку, антибот-защиту и правила начисления наград.
- Настроить HTTPS, секреты окружения и резервное копирование.
- Указать корректный username бота в `public/app.js`.

## Экономика игры

Новый игрок начинает с 500 игровых TRN и 1000 энергии. Игровые начисления и стоимость улучшений заданы в `server.js`. Изменяйте значения каталога и формулы только после тестирования баланса.

## Безопасность

Никогда не помещайте токен Telegram-бота в клиентские файлы. Храните его только в переменных окружения сервера. Не доверяйте балансу, цене улучшения, идентификатору игрока или наградам, присланным браузером: сервер должен проверять их самостоятельно.
